

📦 Inventory & Order Management (Frontend Only)

A lightweight Inventory & Order Management System built using React (Vite).
This is the frontend-only version designed to showcase product listing, stock level updates, order placement, and order history — all with clean UI and smooth interactions.

This project is perfect for assignments, hackathons, and interview tasks.

🚀 Features
🔹 Inventory Management

Displays product name, price, category, and available stock

Low stock highlighted in red

Smooth card animations and modern UI

🔹 Order Placement

Add multiple items to an order

Select products and quantities

Validates:

Minimum quantity

Stock availability

Automatically reduces stock when order is placed

Instant toast notifications

🔹 Order History

Shows:

Order ID

Total amount

Status

Items list

Clean and readable layout

🔹 Responsive UI

Custom CSS-based design

Gradient background

Styled buttons, cards, and navigation bar

🛠️ Tech Stack

✨ Key Features Explained
✔ Real-time Stock Updates

When an order is placed, the app immediately reduces stock from the inventory.

✔ Multiple Items in One Order

You can add multiple products in a single order and validate them.

✔ Simple State-Based Data Management

Frontend-only, uses useState — no backend required.

📌 Limitations (Honest & Professional)

Since this is a frontend-only version:

Data resets on page refresh

No MongoDB or backend APIs

No persistent storage

A full MERN version can be implemented with:

Node + Express backend

MongoDB

Redux Toolkit
