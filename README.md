This project is a simple yet functional Inventory and Order Management system built using React (Vite). It showcases core features such as viewing product inventory, monitoring stock levels, placing orders, and viewing order history — all handled through React’s state management without any backend. The Inventory page displays products with dynamic stock indicators, while the Order page allows users to add multiple items, validate quantities, and automatically reduce stock after every order. All placed orders appear in a clean and structured Orders page. The UI is fully styled using custom CSS, featuring a modern layout with gradient backgrounds, card components, colored buttons, and smooth hover effects. Although this is a frontend-only application, it effectively demonstrates real-world concepts like stock tracking, form validation, data updates, and interactive UI design. It is ideal for hackathon submissions, frontend assessments, and showcasing practical React development skills.
